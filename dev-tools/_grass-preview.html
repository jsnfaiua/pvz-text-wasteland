📐 三层像素合成设计

层实现解决成本
L0基底biome 平滑色（双线性插值，保留）+ 双层值噪声 vary ±7格间连续过渡、不跳色1× fillRect
L1像素肌理3px 块颗粒噪点（±5 亮度），预渲染 36×36 遮罩瓦片 ×6 变体，按格 hash 选变体 drawImage 叠加消除"油漆绿板"平板感，获得像素材质颗粒1× drawImage
L2草叶簇预渲染 3 种草叶图案瓦片（簇状短草 / 散草 / 带花点）：50% 格 1 簇、20% 2 簇、30% 空；草叶深/亮 12% 交替形成光影；花点 <10% 低频低饱和从"随机噪点"变"有图案的草"，立体感0~2× drawImage（按概率）
±光斑每格 1-2 个 2×2 暖色亮点（低 alpha），hash 低频出现阳光透射感，打破死板并入 L1 瓦片
🎨色板每 biome 3 档色（深/中/浅），肌理与草叶在三档间采样色彩层次从 1 级 → 多级—
性能：瓦片启动时一次性预渲染（9 个 36×36 离屏 canvas），每格每帧 = 1 fillRect + 1~2 drawImage，与现状（fillRect + 2 像素点）几乎等价 → 零帧率风险。纯渲染改动：联机 / 存档 / 碰撞 零影响。
