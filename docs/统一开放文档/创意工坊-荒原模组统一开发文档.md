## 1. 模组定位

### 1.1 名称

创意工坊玩法：**无尽植僵荒原**。

### 1.2 核心体验

这是一个诡异、压抑的像素末日生存世界。旧世界遭到文字入侵，名称不再只是标签，而成为现实物质的结构。玩家搜索残缺汉字和稀有字楔，将正确的词固定起来，让文字缓慢具现为具有真实功能的像素物体。

正常的人、NPC、幸存者、植物和物体保持完整像素画。只有感染者才会逐步出现字符闪烁、错位、身体缺损和笔画骨骼，最终失去原本身份。

### 1.3 核心循环

```text
探索荒原、城区与建筑
→ 搜索完整物体、残缺物、字块、字楔
→ 判断字块来源、清晰度、污染度和相容性
→ 在拼字台固定正确名称
→ 经历定词、生形、赋质、落实
→ 获得可用像素物资、工具、武器或设施
→ 生存、种植、战斗、建造并抵御文字感染
```

核心资源抉择是：有限的字楔应该优先让什么东西成为现实。

## 3. 世界核心法则

### 3.1 名称就是物质结构

- 完整名称：物体稳定存在，具有正常外观和功能。
- 缺字名称：对应结构产生像素缺口，部分功能失效。
- 错字名称：组合失败，或形成经过明确设计的畸变物。
- 污染名称：物体能够存在，但携带侵蚀或副作用。
- 名称消散：物体失去现实依据并逐渐消失。

示例：只有“胡萝卜”三个字正确、完整且被字楔固定后，世界才承认它是一根可以食用或种植的胡萝卜。

### 3.2 世界不会承认任意组合

组合必须同时满足：

- 词义成立，且对应具体物体或已登记概念。
- 字符顺序正确。
- 字块来源、清晰度和污染度可以相容。
- 拥有相应等级和数量的字楔。
- 玩家已经通过图鉴、图纸、见闻或NPC知识认知该概念。
- 复杂物体需要现实基底、设备、空间或足够具现时间。

### 3.3 正常与感染的视觉边界

- 未感染角色必须是完整、稳定、可读的像素角色。
- 未感染角色不能无缘无故碎成汉字。
- 文字不是装饰贴图，而是被侵蚀后暴露出来的现实结构。
- 感染必须逐步发生，不得一帧切换成“满身文字”。
- 风格保持诡异、克制、压抑，禁止霓虹赛博、彩色故障风和喜剧乱码。

### 4.4 地点字块生态

- 农田、温室：植物、食物、水分和种植字块。
- 超市、厨房：食物、容器、燃料和日用品字块。
- 医院、诊所：医疗与洁净相关字块，污染和竞争风险较高。
- 学校、图书馆：字块数量多、概念图鉴丰富，感染体密集。
- 印刷厂、档案室：字楔、清晰字块和旧世界词典。
- 工厂、仓库：材料、工具、机械和高现实重量字块。
- 感染区：稀有字块更多，但污染字和诱饵词显著增加。

### 4.5 僵尸战利品袋设计

现有战利品袋已有普通、稀有、史诗品质，能生成资源、弹药、工具和武器。后续文字化改造应遵循：

- 普通袋：基础字块为主，污染风险较高，完整物极少。
- 稀有袋：职业、装备或残名相关字块，可能出现稳定字楔。
- 史诗袋：稀有字、洁净/感染字楔、轻度残缺物或极低概率完整物。
- 不同僵尸类型使用专属字池，避免所有僵尸掉同一批字。
- 人体或感染来源字块不能默认安全用于食物和日用品。

## 5. 字块、字楔与相容性

### 5.1 字块属性目标

| 属性 | 取值示例 | 状态 |
| --- | --- | --- |
| 字符 | 胡、萝、卜 | ✅ |
| 数量 | 可堆叠整数 | ✅ |
| 来源 | 自然、工业、医疗、人体、档案、感染区 | ⬜ |
| 清晰度 | 完整、磨损、残缺 | ⬜ |
| 污染度 | 纯净、不稳、感染 | ⬜ |
| 字性 | 主体、用途、材料、形态 | ⬜ |
| 现实重量 | 决定字楔与具现成本 | ⬜ |
| 耐久 | 拆解、净化和重复使用产生损耗 | ⬜ |

### 5.2 相容反馈

- 白色实线：稳定相容。
- 黄色抖动线：可以连接，但品质或耐久下降。
- 红色断线：组合无效或严重冲突。
- 黑色渗字：可以强行连接，但必然产生感染风险。
- 无反应：词义不存在、字序错误或概念未解锁。

反馈必须同时使用颜色、线型、图标和动画，不能只依赖颜色。

### 5.3 字楔

字楔不会创造物质，只负责固定相容字符之间的意义，让现实开始承认完整名称。基本规则为每个字符连接消耗一个连接单位。

| 类型 | 用途 | 状态 |
| --- | --- | --- |
| 粗制字楔 | 食物、基础材料和简单物件 | ✅ |
| 稳定字楔 | 工具、武器、枪械和机械物品 | ✅ |
| 洁净字楔 | 隔离少量污染或固定高要求概念 | ✅ 基础版；净化效果未开发 |
| 古老字楔 | 建筑、设备和大型世界概念 | ⬜ |
| 感染字楔 | 强行连接污染或不稳字块 | ⬜ |

尚未开发：字楔耐久、损坏、降级、回收、修复和高等级替代规则。

## 8. 残缺物、畸变物与感染

### 8.1 残缺物

- “手＿筒”：保留筒身和灯头轮廓，但无法发光。
- “急救＿”：可以容纳物品，但不能触发快速治疗。
- “胡萝＿”：保留部分植物轮廓，但不能正常食用或种植。

缺字与功能的对应关系由配方数据明确规定，不使用任意自然语言自动推断。

### 8.2 畸变物

- 语义成立的错词可以形成经过人工设计的特殊物品。
- 污染字块可以给正常物品增加危险能力或副作用。
- 感染字楔可以跳过部分相容限制，但结果不可完全预测。
- 畸变风险必须提前提示，不能无提示摧毁玩家的重要资源。

“胡萝怖”等创意只作为方向，必须逐项审核后才能加入正式配方。

### 8.3 生命感染阶段

| 阶段 | 名称 | 视觉表现 | 游戏影响 | 状态 |
| ---: | --- | --- | --- | --- |
| 0 | 完整 | 纯像素角色 | 无影响 | ⬜ 数据未接入 |
| 1 | 浮字 | 表面偶发字符闪烁 | 可检测、轻微压力 | ⬜ |
| 2 | 缺口 | 局部像素缺失并被字块填充 | 对应部位能力下降 | ⬜ |
| 3 | 字骨 | 笔画替代肌肉、骨骼或枝干 | 动作僵硬、出现异常能力 | ⬜ |
| 4 | 失名 | 姓名或身份词残缺 | 记忆、对话和阵营异常 | ⬜ |
| 5 | 文尸 | 像素身份被文字结构取代 | 转化为文字感染体 | ⬜ |

感染者可出现字符闪烁、字符错位和身体缺损。游戏设置中必须提供“减少闪烁”和“降低侵蚀特效”选项，但尚未实装。

### 8.4 文字僵尸

| 类型 | 能力方向 | 状态 |
| --- | --- | --- |
| 残名尸 | 保留部分人形和旧名字，对特定称呼有反应 | ⬜ |
| 拼接尸 | 多个不相容人体词块连接，肢体异常 | ⬜ |
| 删字尸 | 暂时删除角色或物品名称中的关键字 | ⬜ |
| 换字尸 | 污染玩家正在拼合的名称 | ⬜ |
| 活字巢 | 固定在建筑中，持续产生字块和感染体 | ⬜ |

战斗状态方向：删字、污字、固字、散字、夺字。应集中在关键敌人和关卡中，不能让普通战斗持续弹出文字面板。

## 9. 城区、建筑与楼层

### 9.1 区域

| 区域 | 玩法定位 | 主要资源 |
| --- | --- | --- |
| 城区 | 建筑密集、风险高、室内资源丰富 | 医疗、武器、档案、机械 |
| 郊区 | 房屋、院落和道路混合 | 食物、木材、生活物资 |
| 荒野 | 视野开阔、自然资源和野生植物 | 木材、石块、种植资源 |
| 废墟 | 污染与高风险搜索 | 稀有字、零件、异常物 |

### 9.2 建筑分型目标

- 住宅：食物、生活物资、床、储物和幸存者事件。
- 医院：医疗物资、洁净字块、感染风险。
- 学校/图书馆：概念图鉴、字块和文字感染体。
- 仓库/工厂：材料、工具、机械零件和高现实重量物资。
- 商店/超市：食物、容器、日用品。
- 档案室/印刷设施：字楔、词典、清晰字和旧世界记录。

### 9.3 楼层框架

- 地上层当前规划上限为3层，入口层记为第1层。
- 地下层当前规划上限为2层。
- 学校、医院、仓库等建筑可生成地下层。
- 更深楼层提高僵尸数量、生命和掉落品质。
- 室内箱搜索结果需要随存档保存，防止重复刷新。

后续需要补齐：楼梯交互、楼层地图、建筑类型专属房间、地下污染、固定拼字台和楼层事件。

## 10. 像素美术与特效规范

### 10.1 核心原则

- 健康现实是完整像素画。
- 文字是结构，不是装饰。
- 具现时功能部位优先生长。
- 轮廓必须清晰，避免缩小时变成色块。
- 使用有限色板、硬边缘和整数倍缩放。
- 禁止平滑插值、半像素位移和大量柔和渐变。

### 10.2 当前实现

- 具现预览使用72×36低分辨率Canvas。
- 关闭图像平滑，使用CSS整数放大。
- 胡萝卜、草药、木材有专用像素结构。
- 食物、材料、工具、刀剑、弓、枪械和弹药有分类轮廓。
- 物体部件按进度逐步出现，不瞬间切换。
- 当前属于程序绘制的可辨识预览，不是最终逐件精修精灵图。

### 10.3 世界色彩方向

- 背景：近黑、墨绿、灰褐。
- 正常像素：低饱和土色、旧纸色、暗金属色。
- 稳定文字：灰白、旧纸黄。
- 字楔：暗铜、旧金和冷灰绿。
- 感染：暗红、黑紫、病态灰绿，仅用于危险重点。

### 10.4 感染特效限制

- 闪烁只用于感染或不稳定状态。
- 闪烁不能覆盖全部角色，也不能长时间高频持续。
- 字符错位应保留原角色轮廓，使感染进度可读。
- 身体缺损需要与能力损失对应。
- “减少闪烁”开启后改用明暗缓变、轮廓偏移和静态裂隙。
- “降低侵蚀特效”开启后减少字符密度、错位幅度和粒子数量。

### 10.5 素材建议

首批正式母版：胡萝卜、手枪、木墙、汽车、豌豆射手、幸存者。每个母版需包含健康形态、四阶段具现或感染反向阶段，以及低动态版本。

## 11. 界面与操作

### 11.1 当前拼字台使用

1. 进入荒原模式。
2. 搜索物资箱或室内箱，取得字块和字楔。
3. 按 `K` 打开拼字台。
4. 使用顶部分类选择物品。
5. 配方会显示缺少的字符和字楔。
6. 点击“预览效果”可免费查看具现动画。
7. 材料齐全时点击“开始具现”。
8. 按 `K` 或 `Esc` 中断，当前版本会返还材料。

### 11.2 目标界面

- 搜索结果从场景物体附近逐个显露，完整物显示剪影，残缺物显示缺口和字槽。
- 字块背包默认按字符堆叠，可展开查看来源、清晰度、污染度和耐久。
- 支持锁定稀有字块、防止自动填入和误用。
- 提供“可修复物”筛选。
- 拼字台显示配方、字槽、连接点、字楔槽、相容反馈和具现预览。
- 可访问性设置必须包含减少闪烁、降低侵蚀强度，并响应系统低动态偏好。
