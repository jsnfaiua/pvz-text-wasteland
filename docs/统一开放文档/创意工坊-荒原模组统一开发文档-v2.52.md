## 1. 模组定位

### 1.1 名称

创意工坊玩法：**无尽植僵荒原**。

### 1.2 核心体验

这是一个诡异、压抑的像素末日生存世界。旧世界遭到文字入侵，名称不再只是标签，而成为现实物质的结构。玩家搜索残缺汉字和稀有字楔，将正确的词固定起来，让文字缓慢具现为具有真实功能的像素物体。

正常的人、NPC、幸存者、植物和物体保持完整像素画。只有感染者才会逐步出现字符闪烁、错位、身体缺损和笔画骨骼，最终失去原本身份。

### 1.3 核心循环

```text
探索荒原、城区与建筑
→ 搜索完整物体、残缺物、字块、字楔
→ 判断字块来源、清晰度、污染度和相容性
→ 在拼字台固定正确名称
→ 经历定词、生形、赋质、落实
→ 获得可用像素物资、工具、武器或设施
→ 生存、种植、战斗、建造并抵御文字感染
```

核心资源抉择是：有限的字楔应该优先让什么东西成为现实。

### 2.2 已实装的文字具现链路

```text
搜索物资箱或室内箱
→ 获得 glyph:汉字 / wedge:字楔
→ 按 K 打开拼字台
→ 选择分类与配方
→ 检查并消耗对应字块和字楔
→ 定词 / 生形 / 赋质 / 落实
→ 成品进入背包
```

已完成规则：

- 字块以 `glyph:汉字` 形式存入背包并可堆叠。
- 粗制、稳定、洁净三类字楔已经注册。
- 配方检查字符、数量和指定字楔等级。
- 不允许任意汉字自由生成未登记物品。
- 具现过程中关闭拼字台，会返还投入材料。
- 背包满导致成品无法放入时，会返还材料。
- 可免费预览具现效果。

## 3. 世界核心法则

### 3.1 名称就是物质结构

- 完整名称：物体稳定存在，具有正常外观和功能。
- 缺字名称：对应结构产生像素缺口，部分功能失效。
- 错字名称：组合失败，或形成经过明确设计的畸变物。
- 污染名称：物体能够存在，但携带侵蚀或副作用。
- 名称消散：物体失去现实依据并逐渐消失。

示例：只有“胡萝卜”三个字正确、完整且被字楔固定后，世界才承认它是一根可以食用或种植的胡萝卜。

### 3.2 世界不会承认任意组合

组合必须同时满足：

- 词义成立，且对应具体物体或已登记概念。
- 字符顺序正确。
- 字块来源、清晰度和污染度可以相容。
- 拥有相应等级和数量的字楔。
- 玩家已经通过图鉴、图纸、见闻或NPC知识认知该概念。
- 复杂物体需要现实基底、设备、空间或足够具现时间。

### 3.3 正常与感染的视觉边界

- 未感染角色必须是完整、稳定、可读的像素角色。
- 未感染角色不能无缘无故碎成汉字。
- 文字不是装饰贴图，而是被侵蚀后暴露出来的现实结构。
- 感染必须逐步发生，不得一帧切换成“满身文字”。
- 风格保持诡异、克制、压抑，禁止霓虹赛博、彩色故障风和喜剧乱码。

## 4. 搜索、掉落与战利品

### 4.1 统一掉落结构

搜索容器时，原有基础资源掉落与文字系统掉落分开结算：

1. 先结算原有食物、材料、弹药、工具等基础掉落。
2. 再进行一次“文字系统附加结果”判定。
3. 附加结果只能命中一种类别，避免一次搜索同时大量产出字块、字楔和完整物。
4. 表内“完整具象物”概率是每次成功搜索的实际概率，不是二次条件概率。
5. 所有概率必须由具名配置表读取，并在自动测试中校验总和为100%。

文字系统附加结果分为：

| 结果类别 | 说明 | 当前状态 |
| --- | --- | --- |
| 无文字结果 | 本次只保留原有基础物资 | ✅ 原有行为存在；待接统一表 |
| 独立字块 | 掉落1—3个字符，字符按来源池抽取 | 🟡 基础版存在；来源池待接入 |
| 字楔 | 按来源抽取粗制、稳定、洁净或感染字楔 | 🟡 三类基础字楔已存在 |
| 轻度残缺物 | 通常缺1个字，补齐后恢复完整功能 | ⬜ |
| 严重残缺物 | 缺2个或更多字，只有部分轮廓或功能 | ⬜ |
| 完整具象物 | 直接获得可使用的完整物体 | 🟡 原有物品可掉落；统一概率待接入 |

缺字补偿池规则：

- 从玩家已解锁且正在追踪的配方中，统计当前缺少字符。
- 在缺少字符之间等权抽取，不直接生成完整物。
- 若没有追踪配方，则从全部已解锁配方的缺少字符中抽取。
- 若玩家当前没有任何缺字，则回退到物资池。
- 同一配方连续8次文字结果仍未出现关键缺字时，该字在补偿池中的权重提高至3倍；获得后重置。

## 5. 字块、字楔与相容性

### 5.1 字块属性目标

| 属性 | 取值示例 | 状态 |
| --- | --- | --- |
| 字符 | 胡、萝、卜 | ✅ |
| 数量 | 可堆叠整数 | ✅ |
| 来源 | 自然、工业、医疗、人体、档案、感染区 | ⬜ |
| 清晰度 | 完整、磨损、残缺 | ⬜ |
| 污染度 | 纯净、不稳、感染 | ⬜ |
| 字性 | 主体、用途、材料、形态 | ⬜ |
| 现实重量 | 决定字楔与具现成本 | ⬜ |
| 耐久 | 拆解、净化和重复使用产生损耗 | ⬜ |

### 5.2 相容反馈

- 白色实线：稳定相容。
- 黄色抖动线：可以连接，但品质或耐久下降。
- 红色断线：组合无效或严重冲突。
- 黑色渗字：可以强行连接，但必然产生感染风险。
- 无反应：词义不存在、字序错误或概念未解锁。

反馈必须同时使用颜色、线型、图标和动画，不能只依赖颜色。

### 5.3 字楔

字楔不会创造物质，只负责固定相容字符之间的意义，让现实开始承认完整名称。基本规则为每个字符连接消耗一个连接单位。

| 类型 | 用途 | 状态 |
| --- | --- | --- |
| 粗制字楔 | 食物、基础材料和简单物件 | ✅ |
| 稳定字楔 | 工具、武器、枪械和机械物品 | ✅ |
| 洁净字楔 | 隔离少量污染或固定高要求概念 | ✅ 基础版；净化效果未开发 |
| 古老字楔 | 建筑、设备和大型世界概念 | ⬜ |
| 感染字楔 | 强行连接污染或不稳字块 | ⬜ |

尚未开发：字楔耐久、损坏、降级、回收、修复和高等级替代规则。

## 8. 残缺物、畸变物与感染

### 8.1 残缺物

- “手＿筒”：保留筒身和灯头轮廓，但无法发光。
- “急救＿”：可以容纳物品，但不能触发快速治疗。
- “胡萝＿”：保留部分植物轮廓，但不能正常食用或种植。

缺字与功能的对应关系由配方数据明确规定，不使用任意自然语言自动推断。

### 8.2 畸变物

- 语义成立的错词可以形成经过人工设计的特殊物品。
- 污染字块可以给正常物品增加危险能力或副作用。
- 感染字楔可以跳过部分相容限制，但结果不可完全预测。
- 畸变风险必须提前提示，不能无提示摧毁玩家的重要资源。

“胡萝怖”等创意只作为方向，必须逐项审核后才能加入正式配方。

### 8.3 生命感染阶段

| 阶段 | 名称 | 视觉表现 | 游戏影响 | 状态 |
| ---: | --- | --- | --- | --- |
| 0 | 完整 | 纯像素角色 | 无影响 | ⬜ 数据未接入 |
| 1 | 浮字 | 表面偶发字符闪烁 | 可检测、轻微压力 | ⬜ |
| 2 | 缺口 | 局部像素缺失并被字块填充 | 对应部位能力下降 | ⬜ |
| 3 | 字骨 | 笔画替代肌肉、骨骼或枝干 | 动作僵硬、出现异常能力 | ⬜ |
| 4 | 失名 | 姓名或身份词残缺 | 记忆、对话和阵营异常 | ⬜ |
| 5 | 文尸 | 像素身份被文字结构取代 | 转化为文字感染体 | ⬜ |

感染者可出现字符闪烁、字符错位和身体缺损。游戏设置中必须提供“减少闪烁”和“降低侵蚀特效”选项，但尚未实装。

| 类型 | 能力方向 | 状态 |

## 10. 像素美术与特效规范

### 10.1 核心原则

- 健康现实是完整像素画。
- 文字是结构，不是装饰。
- 具现时功能部位优先生长。
- 轮廓必须清晰，避免缩小时变成色块。
- 使用有限色板、硬边缘和整数倍缩放。
- 禁止平滑插值、半像素位移和大量柔和渐变。

### 10.2 当前实现

- 具现预览使用72×36低分辨率Canvas。
- 关闭图像平滑，使用CSS整数放大。
- 胡萝卜、草药、木材有专用像素结构。
- 食物、材料、工具、刀剑、弓、枪械和弹药有分类轮廓。
- 物体部件按进度逐步出现，不瞬间切换。
- 当前属于程序绘制的可辨识预览，不是最终逐件精修精灵图。
- 地图树木已经由单字改为完整像素树冠与树干。
- 房屋屋顶、入口和汽车保持像素主体，并可按感染程度出现局部字符缺口。
- 地图实体感染由世界种子、坐标和区域决定，同一地点不会每帧随机变化。
- 废墟感染比例最高，城区次之，荒野最低。
- 僵尸生成时约46%保持健康像素形态，约36%为局部感染，约18%接近完全文字化。
- 健康僵尸显示完整像素身体；局部感染只替换部分头部、躯干或肢体；完全感染才以“僵/障/桶”等文字结构为主。
- 当前视觉感染只改变画面，不影响实体生命、功能和战斗数值。
- 独立物体遵循“一件物体对应一个名称”；多单元格建筑改为按结构单元分别对应“墙、砖、门、板”。
- 局部感染从物体的一个边缘擦除像素，只显示底层完整名称被该缺口裁切到的部分，不生成多个小字。
- 完全文字化时，完整名称占用与原像素物体相同的整体边界和体型。
- 房屋不再使用整栋词核：外围屋体格文字化为“墙”，内部屋体格文字化为“砖”，入口格文字化为“门”。
- 具象形态和文字形态统一使用2×2逻辑像素，不再混用平滑字体与像素物体。
- 每个逻辑像素拥有独立侵蚀阈值；感染加深时，实体像素逐点消失，文字笔画像素逐点生成。
- 半感染物体可以在同一轮廓内同时存在实体像素与名称笔画像素，不使用整块裁切遮罩。
- 具象色不会直接跳到文字色：每个感染像素按“实体材质色 → 侵蚀过渡色 → 最终文字色”三段插值。
- 侵蚀前沿保留一圈短暂的中间色像素带，再逐点缺损并显出文字笔画，避免实体与文字边界生硬割裂。
- 树木、房屋墙砖、门、室内墙地板、汽车/残骸和僵尸分别使用符合自身材质的过渡色，不共用单一灰色滤镜。
- 树木具象形态与“树 木”文字形态已经合并为同一张28×29状态网格，每个像素格每帧只计算、绘制一次。
- 树木原有树冠和树干像素先在自身位置由材质色转为侵蚀色；属于文字笔画的格子继续转为文字色，其余格子随后缺损。
- 树木不再使用“先绘制实体、再覆盖文字侵蚀层”的双层方案，半感染画面由原具象像素自身重组产生。
- 室内外围墙格文字化为“墙”，中央木地板格文字化为“板”，每个单元格独立计算侵蚀像素。
- 树木文字形态使用28×29像素范围，与树木具象形态的感染轮廓宽高完全一致。
- “树”和“木”分别在独立字符格中栅格化，中间固定保留2像素空隙，避免笔画粘连。
- 树木文字使用1×1精细逻辑像素提高汉字可读性，仍关闭平滑插值并保持硬像素边缘。
- 汽车与残骸使用完整车体宽高生成“汽车/残骸”像素字形，字符间隔3像素。
- 僵尸文字形态固定使用清晰的“僵尸”二字，与28×36像素占格范围一致；装备类型继续由像素外观区分。
- 玩家约28×33像素、僵尸约28×36像素、植物约28×30像素，均围绕36×36地图格校准。
- 各类实体的消失像素与文字笔画像素可以使用不同粒度：实体以2—3像素块侵蚀，文字以1像素精度生成。
- 树木、汽车、残骸、房屋和僵尸使用各自的低饱和侵蚀文字色。

### 10.3 世界色彩方向

- 背景：近黑、墨绿、灰褐。
- 正常像素：低饱和土色、旧纸色、暗金属色。
- 稳定文字：灰白、旧纸黄。
- 字楔：暗铜、旧金和冷灰绿。
- 感染：暗红、黑紫、病态灰绿，仅用于危险重点。

### 10.4 感染特效限制

- 闪烁只用于感染或不稳定状态。
- 闪烁不能覆盖全部角色，也不能长时间高频持续。
- 字符错位应保留原角色轮廓，使感染进度可读。
- 身体缺损需要与能力损失对应。
- “减少闪烁”开启后改用明暗缓变、轮廓偏移和静态裂隙。
- “降低侵蚀特效”开启后减少字符密度、错位幅度和粒子数量。

### 10.5 素材建议

首批正式母版：胡萝卜、手枪、木墙、汽车、豌豆射手、幸存者。每个母版需包含健康形态、四阶段具现或感染反向阶段，以及低动态版本。

## 11. 界面与操作

### 11.1 当前拼字台使用

1. 进入荒原模式。
2. 搜索物资箱或室内箱，取得字块和字楔。
3. 按 `K` 打开拼字台。
4. 使用顶部分类选择物品。
5. 配方会显示缺少的字符和字楔。
6. 点击“预览效果”可免费查看具现动画。
7. 材料齐全时点击“开始具现”。
8. 按 `K` 或 `Esc` 中断，当前版本会返还材料。

### 11.2 目标界面

- 搜索结果从场景物体附近逐个显露，完整物显示剪影，残缺物显示缺口和字槽。
- 字块背包默认按字符堆叠，可展开查看来源、清晰度、污染度和耐久。
- 支持锁定稀有字块、防止自动填入和误用。
- 提供“可修复物”筛选。
- 拼字台显示配方、字槽、连接点、字楔槽、相容反馈和具现预览。
- 可访问性设置必须包含减少闪烁、降低侵蚀强度，并响应系统低动态偏好。
