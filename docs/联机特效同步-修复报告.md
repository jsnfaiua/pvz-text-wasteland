# 联机特效/音效双向同步修复报告

## 修复的 Bug

**客人看不到房主的近战武器挥击特效**——根因：挥击弧光渲染（`render.js` 按 `swingTimer > 0 && swingWeapon` 绘制）需要 `swingWeapon` 字段，而房主快照只发了 `swingTimer`/`swingDir`，漏发 `swingWeapon`，导致客人端房主角色（dave2）的弧光永远不绘制；且挥击音效只在房主本地播放。

## 一、特效/玩法盘点表

| 项目 | 单机表现 | 联机原状态 | 本次处理 |
|---|---|---|---|
| 近战挥击弧光（刀/矛/铲等） | swingTimer+swingWeapon+swingDir 画弧光 | 客人看不到房主挥击（缺 swingWeapon）；房主看客人正常 | 快照 hostPlayer 补 `swingWeapon`；新增 `atk` 事件即时复现 |

## 二、改动文件清单

仅改动 1 个文件：`source-code/multiplayer/mpGame.js`（共 8 处编辑）

1. `sendSync` effects 快照：白名单补 `angle/color/ghosts`，过滤 `muzzle`（改走事件）
2. `sendSync` hostPlayer：补 `swingWeapon`、`perfectFlash`
3. `handleHostSync` hostPlayer：接收 `swingWeapon`/`perfectFlash`，完美格挡上升沿播音效
4. `handleHostSync` effects 映射：接收 `angle/color/ghosts`
5. `hostFire` 铲植物分支：发 `atk` 事件
6. `hostFire` 末尾：发 `atk` 事件
7. `handleMpEvent`：新增 `atk`、`fx` 两个分支
8. `updateMpHostGame` 末尾：新增瞬时音效事件 diff（boom/mower/armorBreak/chomp/dig，`_mpSent` 去重标记不进快照）

## 三、新增事件类型与字段

### `atk`（房主 → 客人，出手瞬间）
| 字段 | 说明 |
|---|---|
| `w` | 武器 key（如 sword/spear/pistol） |
| `kind` | `melee` / `ranged` |
| `angle` | 出手方向（弧度） |
| `x` / `y` | 房主出手位置（y 已减 jumpOffset） |

客人端行为：近战→设置 dave2 挥击三要素 + playWeaponSwing；远程→playBowFire/playWeaponShot + 本地 `_local` muzzle。

### `fx`（房主 → 客人，瞬时音效）
| 字段 | 说明 |
|---|---|
| `kind` | `boom` / `mower` / `armorBreak` / `chomp` / `dig` |
| `radius` | 仅 boom：爆炸半径（≥115 判樱桃，否则土豆雷） |

### 快照新增字段
- `hostPlayer.swingWeapon`、`hostPlayer.perfectFlash`
- `effects[].angle`、`effects[].color`、`effects[].ghosts`
- 快照 effects 不再携带 `muzzle`（事件即时复现替代）

## 五、不适合同步项及原因

| 项目 | 原因 |
|---|---|
| 普通命中音效（playBulletHit/playMeleeHit） | 命中频率高（冲锋枪 0.1s/发），逐发发事件浪费带宽且噪音轰炸；画面反馈（hurtFlash/hit 特效）已由快照同步，开火音效已由 `atk` 覆盖 |
| sunfly/sunpop（阳光飞行/浮字） | 飞行目标是各端自己的 HUD 坐标，两端屏幕坐标系不同，各自本地生成 |
| coinburst/coinfly（钱币爆光/飞行） | 货币归各自账户，飞行目标是本机钱包坐标，`credit`/`bagpick` 事件已驱动本地生成 |
| 狙击开镜视角（aiming 缩放） | 纯本机视口效果；对散射的影响已随 attack 事件的 `aim` 字段在房主端权威判定 |
| 换弹动作/音效 | 本机行为，HUD 各自显示，不影响对方画面与权威状态 |
| 客人自身的挥击/枪口 | 客人本地乐观表现零延迟，房主端由 `handleGuestInput` 回放；快照回传会覆盖本地表现反而引入延迟抖动 |

# 第二轮：格挡/护甲同步修复（3 个 Bug）

全部改动仍只在 `source-code/multiplayer/mpGame.js`（共 10 处编辑），不破坏单机。

## Bug 1：远端玩家完美格挡光环永驻不消

| 项 | 内容 |
|---|---|
| 根因 | `perfectFlash` 只在 `updatePlayer`（本地玩家）衰减；远端 dave2 走 `finishPlayerTimers` + `updateRemoteDashFx`，均无此项衰减 |
| 修复 | `updateRemoteDashFx`（mpGame.js:655）补 `if (p.perfectFlash > 0) p.perfectFlash -= dt;`——两台机器都对各自的远端玩家跑此函数，两端同修 |
| 附带收益 | 修复前客人端 `handleHostSync` 的 perfectFlash 上升沿音效检测因光环永驻只能播一次，现在重复防反可正常重复播音 |

## Bug 2：客人防反成功，自己屏幕无光环无音效

| 项 | 内容 |
|---|---|
| 根因 | 防反判定只在房主端 `checkPlayerDamage(dave2)` 权威执行，光环/音效全发生在房主机器 |
| 修复（发送端） | `updateMpHostGame` 调用 `checkPlayerDamage(dave2, dt)` 前记录 `_pfBefore`，调用后 perfectFlash 上升 → `Net.mp.send('evt', { type: 'pguard' })`（mpGame.js:453-458） |
| 修复（接收端） | `handleMpEvent` 新增 `'pguard'` 分支：`dave.perfectFlash = 0.35; AudioSystem.playPerfectGuard();`（mpGame.js:276-279），本地衰减由 `updatePlayer` 负责 |
| 边界 | 房主自己防反走本地逻辑，检测对象是 dave2（客人角色），不会重复播音 |

## Bug 3：客人看不到护甲条 + 远端格挡盾弧方向/颜色不对

### 3A 护甲条/破甲改名/寒冰减速

| 项 | 内容 |
|---|---|
| 根因 | 快照 zombies 缺 `armorHp/maxArmorHp/armorBroken/_slowed`，plants 缺 `armorHp/maxArmorHp`（render.js 285/333/335/344 行渲染依赖） |
| 发送端 | `sendSync` zombies 快照补 `armorHp/maxArmorHp/armorBroken/slowed`，plants 快照补 `armorHp/maxArmorHp`（mpGame.js:681-682, 688） |
| 接收端 | `handleHostSync` 僵尸 existing 更新与新建 push 两处、植物 map 一处，同步补字段（mpGame.js:1035-1036, 1043-1044, 1063） |

### 3B 格挡盾弧方向/完美窗口颜色

| 项 | 内容 |
|---|---|
| 根因 | 盾弧渲染（render.js 906-913）用 `guardFacing`（方向）与 `guardTimer <= 0.3`（完美窗口=黄色），两字段均未同步；且远端无人递增 guardTimer |
| 客人看房主 | hostPlayer 快照补 `guardTimer/guardFacing`（mpGame.js:720），`handleHostSync` 接收（mpGame.js:997-998） |
| 房主看客人 | `sendInput` 补 `guarding/guardTimer/guardFacing`（mpGame.js:766），`handleGuestInput` 赋给 dave2（mpGame.js:811-813）；keys['e'] 驱动的 startGuard/endGuard 保留以维持冷却语义（startGuard 幂等，不冲突） |

## 新增事件/快照字段清单

| 类型 | 名称 | 字段 | 方向 |
|---|---|---|---|
| evt | `pguard` | （无字段） | 房主 → 客人 |
| 快照 | zombies[] | `armorHp, maxArmorHp, armorBroken, slowed` | 房主 → 客人 |
| 快照 | plants[] | `armorHp, maxArmorHp` | 房主 → 客人 |
| 快照 | hostPlayer | `guardTimer, guardFacing` | 房主 → 客人 |
| input | （顶层字段） | `guarding, guardTimer, guardFacing` | 客人 → 房主 |
