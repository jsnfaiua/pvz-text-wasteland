## 一、当前版本结论

文字具现模块已经形成一条可玩的基础链路：

```text
搜索箱子 → 获得字块或字楔 → K键打开拼字台
→ 选择配方 → 检查字块和对应等级字楔
→ 定词 / 生形 / 赋质 / 落实 → 获得可用物品
```

目前属于“基础具现系统可玩，文字侵蚀世界尚未完整落地”的阶段。

| 大项 | 状态 | 当前情况 |
| --- | --- | --- |

| 拼字台与具现流程 | ✅ | 已能完成从文字到物品的四阶段具现 |
| 具现配方 | ✅ | 已登记35个可用配方 |

| 残缺物体 | ⬜ | 已设计，尚无物品数据、掉落和修复玩法 |

## 三、部分开发、需要继续补齐的内容

### 1. 搜索与文字掉落

| 功能 | 状态 | 当前实现 | 仍缺少 |
| --- | --- | --- | --- |
| 箱子掉落字块/字楔 | 🟡 | 物资箱及室内箱已经接入文字资源 | 武器箱、医疗箱、建材箱、汽车尚未使用各自专属文字表 |
| 文字掉落总概率 | 🟡 | 当前基础接入值为24% | 需要按箱型、地区、楼层、搜索深度分别配置 |
| 字楔内部概率 | 🟡 | 文字掉落中16%为字楔 | 需要不同容器使用不同等级权重 |
| 字楔等级权重 | 🟡 | 粗制68%、稳定26%、洁净6% | 目前所有来源共用同一组权重 |
| 汉字权重 | 🟡 | 62%优先基础生存字池，其余从所有配方字中抽取 | 需要为每个汉字和地点建立明确权重表 |
| 完整物体掉落 | 🟡 | 原有箱子仍会直接掉落完整资源、武器和工具 | 还没有统一纳入“完整具象化物体”稀有度规则 |
| 轻度/重度残缺物 | ⬜ | 无 | 需要新增残缺物数据结构、缺字槽、修复和掉落 |

当前概率只是临时接入值，不能视为最终平衡。尤其是物资箱使用同一个随机数连续判断后续普通物资，实际占比并不直观，下一轮应改为可校验且总和为100%的配置表。

## 四、已经设计但尚未开发的内容

### 1. 残缺物与修复

- ⬜ 搜索到“胡萝＿”“手＿筒”等轻度残缺物。
- ⬜ 搜索到缺少多个关键字的重度残缺物。
- ⬜ 物体外观根据缺字位置产生像素缺口和透明断层。
- ⬜ 补入缺字、消耗字楔后恢复完整功能。
- ⬜ 半成品、具现中断、字楔损坏和材料部分损失。

### 2. 字块属性与相容条件

- ⬜ 来源：自然、工业、医疗、人体、档案、感染区。
- ⬜ 清晰度：完整、磨损、残缺。
- ⬜ 污染度：纯净、不稳、感染。
- ⬜ 字性、现实重量、耐久和鉴定状态。
- ⬜ 白色稳定连接、黄色不稳连接、红色排斥、黑色污染连接。
- ⬜ 图鉴、知识或图纸对配方的解锁限制。

当前只检查“字符是否正确、数量是否足够、字楔等级是否正确”，还没有来源与污染等深层相容判定。

### 3. 更多字楔

- ⬜ 古老字楔：大型设备、建筑和世界结构。
- ⬜ 感染字楔：强行固定污染组合，但成品带副作用。
- ⬜ 字楔耐久、损坏、降级、回收和修复。
- ⬜ 高等级字楔替代低等级字楔的具体规则。

### 4. 生命感染与视觉变化

- ⬜ 未感染角色保持完整像素形态的统一规范接入。
- ⬜ 感染阶段0至5的数据状态。
- ⬜ 字符闪烁、字符错位、局部身体缺损、笔画替代骨骼。
- ⬜ NPC姓名残缺、记忆异常、工作能力和关系变化。
- ⬜ 玩家感染、检测、稳定和可能的治疗机制。
- ❔ 是否存在真正逆转感染的方法，仍未最终定案。

### 5. 文字僵尸与战斗规则

- ⬜ 残名尸、拼接尸、删字尸、换字尸、活字巢。
- ⬜ 删字、污字、固字、散字、夺字状态。
- ⬜ 植物名称受损及对应功能失效。
- ⬜ 被感染植物逐渐长出汉字枝干。
- ⬜ 僵尸身体文字化的专属像素动画和掉落反馈。

### 6. 世界级具现

- ⬜ 建筑部件、家具、设备和大型拼字台。
- ⬜ 汽车、道路、房屋总名等世界结构的文字稳定性。
- ⬜ 地点专属字块生态和深搜风险。
- ⬜ 印刷厂、档案室、学校等字楔高价值地点。
- ⬜ 聚落NPC委托、交换、鉴定和净化服务。

## 七、使用与配置

### 当前玩家使用方式

1. 进入荒原模式并搜索物资箱或室内箱子，取得汉字字块与字楔。
2. 按 `K` 打开拼字台。
3. 使用顶部分类选择物品；配方列表会显示缺少的材料。
4. 点击“预览效果”可免费查看四阶段像素具现。
5. 材料齐全时点击“开始具现”，完成后物品自动进入背包。
6. 具现过程中按 `K` 或 `Esc` 关闭，会返还本次投入材料。

### 当前开发配置位置

- 基础文字掉落概率、字楔概率：`source-code/mod-wasteland/wwordcraft-rules.js` 中的 `WORDCRAFT_CONFIG`。
- 字楔名称和颜色：同文件中的 `WEDGE_INFO`。
- 具现配方、耗时、产物、字楔等级：同文件中的 `RECIPES`。
- 室内箱、物资箱、武器箱、医疗箱、建材箱和汽车掉落：`source-code/mod-wasteland/survival.js`。
- 僵尸掉袋概率和袋内物品：`source-code/mod-wasteland/wbalance.js` 与 `source-code/mod-wasteland/wzombie.js`。
- 具现像素造型：`source-code/mod-wasteland/wpixelmanifest.js`。

下一轮调整概率时，建议把所有文字掉落和完整物体概率集中为一套具名配置，并加入概率总和测试，避免继续把关键数值分散在多个函数中。
