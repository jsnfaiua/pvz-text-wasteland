# 🎮 文字植物大战僵尸 - 启动说明

## 🚀 快速启动

### 方式 1：双击 BAT（推荐 ✅）
双击 `RUN.bat` 即可！
- 自动清理端口 8000 上的旧服务器
- 启动本地服务器（基于 ps-server.ps1）
- 自动打开浏览器

### 方式 2：PowerShell
右键 `ps-server.ps1` → `使用 PowerShell 运行`
- 直接启动静态文件服务器（端口 8000）
- 浏览器手动打开 http://localhost:8000

### 方式 3：一键联机双开（联机测试推荐 ✅）
双击 `联机对战.bat`：
- 启动游戏服务器（含联机房间中继 PeerServer，端口 9000）
- 自动双开两个**独立**浏览器实例（Chrome 优先，Edge 兜底）
- 两个实例各自独立的账号/存档（独立 user-data-dir），开箱即可联机测试
- 需要 Node.js（提供房间中继；仅静态服务器时联机回退公共云，连接较慢）

## 🌐 联机玩法速查

| 步骤 | 操作 |
|------|------|
| 1 | 玩家 A：多人联机 → 创建房间 → 复制房间码/邀请链接 |
| 2 | 玩家 B：加入房间 → 输入 6 位房间码（或打开邀请链接自动加入） |
| 3 | 玩家 B 点「准备就绪」→ 玩家 A 选关开始（房主需等客人准备） |
| 4 | 荒原联机：房主创建房间 → 好友加入 → 双方各自创建角色后自动进入 |

联机特性：
- **断线自动重连**：客人网络抖动/短暂掉线约 38 秒内自动恢复，重连后自动追平世界状态，无需重开房间
- **准备门槛**：房主在客人准备前无法开局，避免对方还没进房间就开打
- 本体联机与荒原联机的断线重连、准备机制行为一致

## 🔧 手动启动（如果以上不行）

### 方法 A：Python
```bash
# 在游戏目录打开 CMD，运行
python -m http.server 8000

# 浏览器打开
http://localhost:8000
```

### 方法 B：Node.js
```bash
npx serve

# 浏览器打开
http://localhost:3000
```

### 方法 C：PHP
```bash
php -S localhost:8000
```

---

## ❓ 为什么需要服务器？

因为新版本使用了 **ES Module** 模块化架构：
- ✅ 代码清晰，模块化拆分
- ✅ 便于维护和扩展
- ❌ 浏览器安全限制，`file://` 协议无法加载 JS 模块

所以需要本地 HTTP 服务器才能正常运行。
