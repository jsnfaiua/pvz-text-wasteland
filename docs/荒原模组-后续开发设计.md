# 无尽植僵荒原 · 存档功能 + 后续开发设计方案 v3

> 依据：《无尽植僵荒原｜创意工坊模组完整设计文档》+ 用户 v2/v3 定案（2026-07-25）
> 核心定位：文字 2D 生存 + 建筑 + 开放大世界 + 尸潮防守
> 状态：**v3 已定案，第一批开发中**

---

## 已定案事项（2026-07-25 用户拍板）

1. **死亡规则按难度**：模组设置加荒原难度档位——简单/普通 = 软核重生（丢 30% 背包物品，建筑与柜子保留，床边或出生点重生）；困难/地狱 = 硬核清档
2. **阳光培养体系**：阳光是培养植物的战略资源；种子孵化需要 **水 + 肥料 + 阳光** 三样齐备才能长成植物（M6 细化）；中立向日葵 = 战略资源点
3. **尸潮奖励**：随存活天数递增奖池
4. **阶段合并**：M3 建筑 + M4 武器搜刮装备 合并为一批
5. **第一批开工**：M2.5 存档显性化 + M3 建筑 + M4 武器
6. **无限地图**：地图程序化无限生成；每次【新的荒原】创建全新世界（随机世界种子）；【继续荒原】读取存档世界

---

## 一、存档功能（M2.5）

- 工坊详情页：存档摘要（第 N 天 · 存活时长 · 背包 X/24）+【继续荒原】/【新的荒原】（清档二次确认）
- 床边休息 = 存档点；ESC 退出提示"进度已保存"
- 死亡规则按难度（见定案 1）
- 无限地图存档方案：世界种子 + 玩家修改（开过的容器/砍过的树/建筑/柜内容/背包/位置/天数），地形由种子确定性重生成，存档体积小
- 旧版 96×96 存档：优雅降级（提示后开新世界，不报错）

## 二、建筑系统（M3）

- G 建造模式：木墙(木材×2)/木门(×3)/储物柜(×4)/木床(×6)
- 3 格内空地放置；自造建筑 F 拆除返半；原生建筑不可拆
- 储物柜：F 双栏面板（背包 ↔ 柜 12 格）转移，按坐标独立存储，进存档

## 三、武器搜刮与装备（M4）

- 物资箱掉落：近战常见 / 手枪·弓次之 / 步枪·狙击稀有 + 对应弹药
- 武器=背包物品：名称/介绍/属性（伤害/攻速/射程/体力消耗）
- 背包点击装备：近战槽 + 远程槽；攻击模式与音效复用单机武器表（半/全自动、蓄力弓、狙击镜、近战弧/刺）
- 物品介绍面板：背包选中任意物品显示（全物品通用）

## 四、后续阶段

- M5 快捷栏（6 格，数字键快速使用/切换）
- M6 中立植物生态 + **培养系统**：中立植物自动打僵尸、被招惹会反击；掉落种子 → 种子 + 水 + 肥料 + 阳光 → 培养成防御植物（种在自建地块）
- M7 尸潮系统：预警 → 90s 建造窗口 → 多方向进攻 → 奖励随天数递增
- M8 室内独立空间 / M9 载具 / M10 生存循环 / M11 设置扩展

## 五、长期约束

1. 单机关卡形式不进大世界；武器攻击模式/音效、植物机制以搜刮武器/中立生物/培养植物形式复用
2. 大世界战斗主体 = 搜刮武器 + 建筑工事 + 培养植物；尸潮是大世界内事件
3. 每阶段先确认再开发；最简代码；存档向后兼容；本体零侵入；模组沙盒隔离
4. 每阶段交付：语法检查 + 桌面同步 + 中文 UI
