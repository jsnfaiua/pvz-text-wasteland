〇、总览（难度分支）
----------------------------------------------------

死亡（hp 归零）→ onDeath()

  ├─ 掉落惩罚（软核/硬核通用，见 §一）
  │
  ├─ 软核（正常）：倒地救治（见 §二）
  │    ├─ 有队友 → 倒地救治流程（切视角/背人/送药）
  │    └─ 无队友 → 重生 + 重生点刷"玩家名"僵尸
  │
  └─ 硬核（一条命）：无救治（见 §三）
       ├─ 有队友 → 直接切队友视角
       └─ 无队友 → 尸化留世 + 退出主菜单


----------------------------------------------------
一、掉落惩罚（软核/硬核通用）
----------------------------------------------------

【当前实现】
- 死亡时部分物品掉进原地遗物包裹 loot:legacy
- 死亡次数越多，掉落越丰富越稀有（有上限）
  - deathDropRate：第1次10%，每多死 +1%，封顶 90%
  - 按物品价值降序判定（高价值=高稀有度优先掉入包裹）
- 确定性：hash2(seed, 死亡格, 槽位, 次数) 判定（不依赖 Math.random）
- 玩家身上保留一部分物品（不会全掉）

【可调数值】（wbalance.js）
  DEATH_DROP_BASE = 0.1   // 第1次掉落率
  DEATH_DROP_STEP = 0.01   // 每次递增
  DEATH_DROP_MAX  = 0.9    // 封顶

- [ ] 掉落率数值是否需要调整
- [ ] 是否要区分"稀有度等级"（普通/稀有/史诗）单独控制


----------------------------------------------------
二、软核（正常）难度 · 倒地救治
----------------------------------------------------

2.1 死亡掉落
- 死亡 → 掉落惩罚（见 §一）

2.2 有存活队友（NPC 或联机真人）
- 主角进入倒地状态（_downed）
- 视角立即切到最近存活队友，可以进行选择，选择切换或者原地等待
- 倒地主角留在原地（或被背走）
- 队友 AI 行为优先级：
    ① 周围有怪物 → 先战斗，清完才救助
    ② 清完怪 → 有床：背回床旁；无床：原地守候进行救助
- 玩家可自主操作：
    ① 操控队友战斗清怪
    ② 靠近倒地主角按 V 背起，走回床旁/安全点按 V 放下
    ③ 命令面板「背回 XXX」命令其他 NPC 背人
- 救治：
    - 玩家操控队友搜集药品（伤口药/抗生素 1 瓶 或 草药 3 株）
    - 靠近倒地主角按 F 提交药品（可多次/多人累计）
    - 药品集齐 → 主角救活
- 限时：倒地超过 2 游戏天 → 主角彻底死亡，地上保留尸体
    - 再过 1 天 → 重生点刷"玩家名"僵尸

2.3 队友全灭
- 倒地主角之外的所有可行动队友（含联机真人）都阵亡
- 无人能救 → 主角直接死亡 → 软核重生（同普通死亡）

2.4 无存活队友
- 掉落惩罚 + 重生
- 复活点：有床（睡过）→ 床旁；无床 → 随机地点
- 重生点刷"玩家名"僵尸（重生后能看到位置），不会立即刷也是过3天

2.5 可调数值（wbalance.js）
  DOWNED_LIMIT_DAYS = 2       // 倒地限时（游戏天数）
  DOWNED_RESCUE_MED = 'med:wound'  // 救治所需药品
  DOWNED_NEED_MED = 1         // 集齐瓶数（对症药/抗生素）
  DOWNED_HERB_EQUIV = 3       // 草药等价（3株=1瓶）
  DOWNED_PZ_DELAY_DAYS = 1    // 超时后刷尸延迟天数

【待确认/可修改】
- [ ] 倒地限时 2 天是否合适
- [ ] 药品种类/数量是否合适（伤口药/抗生素 1 瓶 或 草药 3 株）
- [ ] 背人键位 V 是否合适
- [ ] 队友全灭触发的重生是否也刷"玩家名"僵尸（当前是刷的）


----------------------------------------------------
三、硬核（一条命）难度 · 无救治
----------------------------------------------------

3.1 死亡掉落
- 掉落惩罚（见 §一）
- 主角尸化留世（spawnPlayerZombie，继承名字/外观/装备）

3.2 有存活队友
- 直接切换队友视角继续（无救治过程）

3.3 无存活队友
- 游戏直接结束：退出主菜单
- 不再弹"保存世界 / 不保存"窗口（2026-08-09 用户定稿）
- 角色档/世界档不保留，不可重新进入

【待确认/可修改】

----------------------------------------------------
四、联机多人
----------------------------------------------------

4.1 队友定义
- 组队真人玩家 = 队友（真实组队，区别于 NPC 队友）
- 每个玩家可招募，或者邀请 3 个 NPC 队伍成员

4.2 真人倒地救助
- 真人死亡 → 另一真人可原地救助（提供药品，提交累计）
- 药品不够 → 可命令倒地玩家的 NPC 成员带领前往重生点治疗，并且寻找药品，
- 倒地玩家可切 NPC 视角自行找药
- 药品提交累计（host 权威）

4.3 联机权威
- 倒地状态 _downed：host 权威，wsync 同步
- 药品提交：downedMed 事件 → host 权威累计
- NPC 命令：复用 npcctl 基础
