## 一、领域概述

本领域是**序列化唯一真相源**（AGENTS.md §4 红线 #2）。`wstate.js` 是唯一允许的白名单序列化模块，存档与联机快照共用同一套白名单字段，杜绝「存档有、快照没」的漂移。采用**泰拉瑞亚式双档**：角色档跟名字、世界档跟种子。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **白名单序列化** | `serializeSV` / `applySnapshot` / `createRunDefaults` / `buildRun` 纯函数，白名单字段；**禁止 `JSON.stringify(sv)`**（sv 含 DOM/canvas/函数引用） |
| **泰拉瑞亚双档** | 角色档 `wasteland_character_<名>`（名字/外观/物品/属性，跨世界保留）；世界档 `wasteland_world_<seed>`（seed/时间/差分 mods/NPC，跟种子走）+ profile（当前角色+世界组合、devMode） |
| **差分存储** | 世界档只存 seed + 差分（`sv.mods.tiles`），读档按 seed 重建基底再叠加差分 |
| **存档迁移** | `buildRun` 加载时自动迁移历史档（如路带内 built SIDEWALK → 还原路面） |
| **宏任务队列落盘** | `saveNow` 用 `_saveQueued` + setTimeout 0 排队；退出/切后台 `flushSave` 兜底，避免 RAF 帧内整包 JSON 落盘（P0-1） |
| **存档缓存清理** | `cleanupStaleSaveCache` 校验选中缓存指向的存档是否存在，不存在则清空，防「删档后仍显示痕迹」 |

## 三、关键代码改动

| 位置 | 改动内容 |
|---|---|
| `wstate.js:serializeSV` | SV 白名单序列化（存档与联机快照共用真相源） |
| `wstate.js:createRunDefaults` | 新档默认值工厂（`buildRun` 内部据此做历史档迁移） |
| `wstate.js:applySnapshot` | 快照回写（读档 / 联机 applyMpSnapshot 复用） |
| `wstate.js:serializeCharacter` / `applyCharacter` | 角色档序列化/回写（跨世界保留名字/外观/物品/属性） |
| `wstate.js:serializeWorld` / `applyWorld` | 世界档序列化/回写（seed + 差分） |
| `wstate.js:serializeMpSnapshot` | 联机快照序列化，支持 34 格空间裁剪（cull 参数） |
| `survival.js:charKey` / `worldKey` | 角色档/世界档 localStorage 键名生成 |
| `survival.js:saveNow` / `flushSave` | 宏任务队列落盘 + 退出/切后台兜底（P0-1 性能防线） |
| `survival.js:migrateLegacySave` | 历史存档迁移（旧档兼容） |
| `survival.js:cleanupStaleSaveCache` | 存档缓存清理（8/9 修复「删档后开始游戏仍显示痕迹」） |

## 四、涉及模块与依赖

```
wstate.js(无环,Node可单测) → 被 survival.js / mpWasteland.js 依赖
  → 环内依赖(B/panel/WNPC/normalizeLook/PLAYER_INFECTION/saveData) 由 survival.js 组装成 STATE_DEPS 注入
survival.js → 主控存档读写，导出给 mpWasteland
```

> 新增持久化/联机同步字段**必须加入 wstate.js 白名单**，禁止 ad hoc 序列化（AGENTS.md §4）。

## 六、历史教训

1. **禁止 `JSON.stringify(sv)`**：sv 含 DOM/canvas/函数引用，会抛错或静默损坏（AGENTS.md §4 红线）。
2. **双档归属**：世界档归 host（联机含双方 wdiff），guest 只落角色档；断线重连 = guest 重连 → `wrejoin` → host 重发 winit（AGENTS.md §6）。
3. **迁移不能省**：新增/变更存档字段必须同步 wstate.js 迁移表，历史档兼容由 `buildRun` 自动处理，禁止跳过迁移直接改读法。
4. **删档痕迹 bug**：8/9 曾因选中缓存指向已删存档导致「删档后仍显示旧痕迹」，需 `cleanupStaleSaveCache` 校验。
5. **改后必跑双验证**：改 wstate.js 后必跑 smoke + full-run，改存档键结构后补双端兼容测试（AGENTS.md §6 教训 10）。
