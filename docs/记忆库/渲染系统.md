## 一、领域概述

荒原渲染：**静态层离屏缓存 + 动态层逐帧**，覆盖昼夜、HUD、驾驶/队伍面板、草、角色染色、特效。与 [玩家系统与捏脸](玩家系统与捏脸.md) 共享角色渲染逻辑（`tintSprite` / `nearestPart`）。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **静态层离屏缓存** | 静态地块/建筑预渲染到离屏 canvas，只重画变更格，避免每帧重绘全图 |
| **动态层逐帧** | 玩家/僵尸/NPC/子弹/特效/草每帧绘制，配合 `dt` 时间步进 |
| **角色像素染色** | `tintSprite` + `nearestPart`（按颜色最近匹配部位再染玩家色）+ MC_PAL 部位色板；是 8/9 多轮杂色修复核心 |
| **特效键控 Map（P0-5）** | 特效合并用 kind + 12px 桶的 Map，O(1)，避免线性 find O(n²) |
| **草分层渲染** | 静态草底（`drawGroundTile` 最底层）+ 动态草层（`grassRenderLayer`）；草束永远不盖物品 |
| **离屏缓存 key（§13.8）** | 外观/状态维度（发型/动画状态/皮肤/季节/朝向）必须加入缓存 key，缺失维度 = 脏读旧缓存 = 颜色错乱 |

## 六、历史教训

1. **角色染色杂色是 8/9 最大战役**：根因多为 MC_PAL 颜色与素材不匹配（非 tint 算法），更新 MC_PAL 匹配实际素材后基础判定就准了；再精确的位置约束根除杂色。核心教训：**对照原图判断**——若 tint 后颜色与原图对应位置的「语义」一致（眉毛是头发→染成发色正确），则不是算法 bug，停止过度修改。
2. **离屏缓存 key 必须含全部外观维度**：缺失维度=脏读旧缓存=颜色错乱（AGENTS.md §13.8 硬性）。
3. **草优先级最低**：草束永远不盖物品，静态草底在最底层、动态草层在物体之下（8/9 调整）。
4. **特效键控 Map 不可回退**：O(1) 合并是特效上限 50 还能流畅的关键（P0-5）。
5. **美术改动先预览**：涉及美术渲染效果的改动必须临时浏览器预览确认后才定稿，并清理临时产物（AGENTS.md §11.10 / §13.12）。
