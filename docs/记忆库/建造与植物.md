## 一、领域概述

建造系统负责在世界上放置/拆除/升级建造物（含受击与返材）；植物系统负责野生植物的物种、生长阶段、攻击与驯化培育。两者均与 `render.js`（BUILD_ITEMS / BUILD_HP）和 `world.js` 交互。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **建造合法性校验** | `buildOkAt`：范围/可站/资源/前置判断 |
| **建造升级** | `placeBuild` 支持 `bitem.upg` 升级链 |
| **拆除返材** | `demolish` 返还 stone/wood/part |
| **受击系统** | `damageBuilding` / `damageObstacle`：建筑/障碍受击（僵尸啃咬调用） |
| **野生植物物种** | `wplants.js WILD_SPECIES` / `SPECIES_KEYS` / `STAGES`：peashooter / repeater / snowpea / chomper / sunflower + 生长阶段（hpMul/dmgMul/sizeMul） |
| **植物攻击** | `updatePlants` 索敌/发射/种间弹丸；`nearestZombie` / `activateNearby` |
| **驯化培育** | `tryTame` / `tryCultivate`：野生 → 可种植 |
| **植物受击** | `damagePlantFromZombie` / `hurtPlant` / `killPlant`：供 wzombie 调用 |

## 六、历史教训

1. **新配方必须进纯规则文件**：合成配方走 `wwordcraft-rules.js RECIPES`（不依赖 DOM/音频/浏览器全局），禁止散落业务代码（AGENTS.md §13.6）。
2. **概率表权重和=1**：掉落/概率表权重和必须=1，在 smoke-test 加断言（AGENTS.md §13.6）。
3. **建造/植物受击与僵尸联动**：改 `damagePlantFromZombie` / `damageBuilding` 时核对僵尸调用方（`wzombie.js updateZombies`）。
4. **新数值须过难度倍率**：新增影响强度的数值对照 `DIFF_TABLE.mul`（hardcore ×1.5）决定是否受缩放（AGENTS.md §13.7）。
