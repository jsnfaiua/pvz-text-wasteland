## 一、领域概述

僵尸 AI 基于**共享反向 A\* 流场**；负责僵尸刷新/尸群/守卫、死亡掉落、武器子弹、感染多阶段、尸化精英僵尸，以及**死亡 v2**（队友救回 / 遗物包裹 / 死亡次数代价）等核心战斗体验。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **共享反向 A\* 流场** | `wpath.js astarField`：以玩家格为起点反向 BFS，一张 parent 表供所有僵尸反查下一格；8 方向、octile 启发式、斜穿禁过两障碍角 |
| **流场性能三连** | ① targets 只取「尸潮 + 玩家警戒范围」；② 换格 `_pathRebuildCd=0.35s` 冷却复用旧场；③ 旗帜光环预收集（O(n×flag)） |
| **感染多阶段** | `winfection.js PLAYER_INFECTION.stages`（多档 hpMul/speedMul）、worldInfectionLevel、playerInfectionEffects、infectionLevelFromRoll |
| **尸潮分批** | `whorde.js updateHorde` 分批放怪 + 场上限 `HORDE_MAX_ONFIELD`；`startHordeWave` 刷旗僵尸领头 + 巨字尸首领（第 3 天起 25% 概率） |
| **死亡 v2** | 正常模式队友救回 + 遗物包裹（掉全部物品/部分永久消失/死亡次数代价递增） |
| **尸化精英** | 玩家死后原角色留世界，继承名字/外观/装备/背包，会用背包远程武器射玩家 |

## 三、关键代码改动

| 位置 | 改动内容 |
|---|---|
| `wzombie.js:buildPlayerPathField` / `getPlayerPathField` | 共享流场 + 换格冷却复用 + targets 近距化（性能 P0-2/P0-8） |
| `wzombie.js:updateZombies` | 主循环：碰撞啃咬（`Z_BITE_RANGE=44` 覆盖相邻格，血条平滑 DPS）、车内护甲、濒死 NPC 被咬扣救援时间、NPC/guest 追击、扑咬/撑杆/旗帜光环/食花路线选择 |
| `wzombie.js:spawnZombie` | 僵尸生成（分配 id），室内生成支持（写入 `interior.zombies`） |
| `wzombie.js:spawnPlayerZombie` | **尸化精英僵尸**：继承名字/外观/装备/背包，会射玩家 |
| `wzombie.js:playerZombieShoot` | 尸化精英射击：`dmg = Math.max(4, round(w.damage*0.7))`，`hostile:true` 可命中玩家 |
| `wzombie.js:rollQualityLoot` / `rollLootContents` | 战利品袋品质掉落（按 tier/强度） |
| `wzombie.js:updateGuardSpawns` | 尸群守卫：`GUARD_TILES`（箱/木箱/医疗箱/材料箱/门）旁刷守卫僵尸 |
| `wzombie.js:updateSpawns` / `updatePackSpawns` / `eliteChanceAt` | 野生刷新 / 尸群（king+follower）/ 精英概率 |
| `wzombie.js` 死亡掉落 | 掉品质袋 + 灵石（`WG.lingDrop`）+ 尸变丧尸被击败掉「XX（尸变）」尸体（物品守恒） |
| `wnpc.js:syncRecordToControlled` | **恶意 NPC 可击败玩家**：移除 `sv.hp = Math.max(1, n.hp)` 覆盖（原把刚扣的血拉回 → 玩家无敌）；玩家 hp 由攻击/回血逻辑控制 |
| `wgear.js:SHOT_ORIGIN_Y = 26` | 子弹/枪口/瞄准以角色手部高度为原点（sprite 高 48，手部约 30） |
| `wgear.js:updateBullets` / `tryFire` / `meleeAttack` / `startCharge` / `releaseBow` | 子弹碰撞/穿透/射程衰减、近战、蓄力弓 |
| `survival.js:deathDropLegacy` | **遗物包裹**：死亡按 `deathDropRate(sv._deathCount)` 掉部分物品进遗物包裹；**保留物品必须 `sv.inv[i]=null`** 否则被复制 |
| `survival.js:softRespawn` | 软核重生：床旁或随机复活；`_pzRespawn` 延迟刷「玩家名」尸化僵尸于 `_lastDeathPos` |
| `survival.js:updateDowned` / `_downedMembers` | 软核倒地救治状态机（队友背回/送药/超时尸变）；濒死次数越多救援窗口越短（20 分钟 / 2^(n-1)，最低 60 秒） |
| `survival.js:onDeath` | 死亡结算：`DEATH_VANISH_BASE` 不可抗力永久消失比例随死亡次数增加；重生=旧队伍解散 |

## 六、历史教训

1. **恶意 NPC 打不死玩家根因**：`syncRecordToControlled` 覆盖了玩家实时 hp，8/8 移除该覆盖才让 NPC 可击败玩家（行为变更）。
2. **僵尸新增必须走 `spawnZombie`**（分配 id），禁止手工 push 无 id 对象，否则联机按 id 合并失效（AGENTS.md §6 教训 9）。
3. **保留物品必须置 null**：遗物包裹保留物品 `sv.inv[i]=null`，否则物品被复制（物品守恒）。
4. **流场是性能主因**：改流场 targets/冷却会直接回退 host 帧率（见 [性能优化](性能优化.md)）。
5. **死亡 v2 复杂状态机**：倒地救治/遗物包裹/死亡代价互相关联，改动必须跑 combat-death-matrix（898 断言）。
