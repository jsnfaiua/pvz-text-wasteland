# 数值平衡与难度 · Agent 记忆

> 所属记忆库：`docs/记忆库/`｜主索引：[`../../AGENTS.md §14`](../../AGENTS.md)
> 相关模块：`mod-wasteland/wbalance.js`（数值收口）、`wgrade.js`（品级/伤害倍率）

---

## 一、领域概述

本领域是**数值唯一收口**（AGENTS.md §13.1 硬性）：所有游戏数值/概率/倍率/属性表必须定义在 `wbalance.js`（或具名 X_INFO 表），禁止业务代码散落魔法数字。难度分为**正常 / 硬核（一条命 ×1.5）**两档。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **数值收口** | 速度/血量/消耗/尸潮阈值/SAVE_INTERVAL 等全在 `wbalance.js`；局部派生常量贴近使用处，源值可追溯 |
| **概率表（权重和=1）** | 掉落表/字源池等权重和必须=1，smoke-test 加断言（AGENTS.md §13.6） |
| **难度倍率联动** | `DIFF_TABLE.mul`：hardcore ×1.5；新增影响强度的数值对照它决定是否受缩放（漏乘=难度失效，AGENTS.md §13.7） |
| **品级系统** | `wgrade.js` 品级灵石 + 伤害倍率（装备/材料品级） |
| **刷新概率集中** | NPC 野外刷新 `WILD_NPC_DAILY_CHANCE`、营地生育 `BIRTH_DAILY_CHANCE`、室内 `INTERIOR_NPC_CHANCE_BASE` 等全在 wbalance |

## 三、关键代码改动

| 位置 | 改动内容 |
|---|---|
| `wbalance.js:DIFF_TABLE.mul` | 难度倍率表（hardcore ×1.5） |
| `wbalance.js:WILD_NPC_DAILY_CHANCE` | 野外 NPC 刷新概率 0.002（8/9 微调 0.15→0.002） |
| `wbalance.js:BIRTH_DAILY_CHANCE` | 营地生育概率 0.005（0.02→0.005） |
| `wbalance.js:INTERIOR_NPC_CHANCE_BASE` / `INTERIOR_NPC_CHANCE_PER_FLOOR` | 室内 2 楼 0.15% + 每高一层 +0.03% |
| `wbalance.js:nearSpawnScreen` | 出生点屏幕保护（半屏 15×9 格，TS=36）：野外/僵尸群/NPC 刷新避开出生点屏幕 |
| `wgrade.js` | 品级灵石 + 伤害倍率 |
| `wbalance.js` 数值常量 | 速度/血量/消耗/尸潮阈值/SAVE_INTERVAL 等（具名 X_INFO 表） |

## 五、验证方式

| 场景 | 命令/做法 |
|---|---|
| 改 wbalance 数值/配方/概率表 | `node dev-tools/smoke-test.js` 数值断言（概率权重和=1、DIFF 倍率映射、配方可达性）+ 受影响系统回归 |
| 改难度档位 | 同步：难度表 / 旧档归一映射 / UI / 存档键（AGENTS.md §13.7） |
| 新数值 | 对照 `DIFF_TABLE.mul` 决定是否受难度缩放（漏乘=缺陷） |

## 六、历史教训

1. **禁止魔法数字**：数值/概率/倍率必须定义在 `wbalance.js` 或具名 X_INFO 表，禁止散落业务代码（AGENTS.md §13.1）。
2. **难度倍率漏乘 = 缺陷**：新增影响强度数值必须对照 `DIFF_TABLE.mul`（hardcore ×1.5），漏乘导致难度失效（AGENTS.md §13.7）。
3. **概率权重和必须=1**：所有概率表权重和=1，smoke-test 有断言，改动必须保持（AGENTS.md §13.6）。
4. **新增难度档位四同步**：难度表 / 旧档归一映射 / UI / 存档键必须一起改（AGENTS.md §13.7）。
5. **刷新概率曾过大**：8/9 曾因野外 15% 刷新导致开局堆人，后降为 0.2%；改概率前核对刷新规则（出生点/营地/室内楼层）。
