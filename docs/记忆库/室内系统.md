# 室内系统 · Agent 记忆

> 所属记忆库：`docs/记忆库/`｜主索引：[`../../AGENTS.md §14`](../../AGENTS.md)
> 相关模块：`mod-wasteland/windoor.js`、`survival.js`（室内交互三函数实际在此）

> ⚠️ **重要定位提示**：`updateInteriorMode` / `doInteriorInteract` / `updateInteriorPrompt` 这「室内三函数」逻辑上属于室内系统（windoor 模块职责），但**代码实现位于 `survival.js`**（`update` 主循环调用）。搜符号时注意。

---

## 一、领域概述

室内系统负责建筑楼层生成、室内移动/交互、躲藏幸存者、室内外 NPC 统一与室内战斗。核心是「室内外逻辑一致」——`updateInteriorMode` 复用室外 `updateNpc` 分发，只是 canStand 换 `interiorCanStand`、sv.zombies 换室内僵尸。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **楼层系统** | `generateInterior`（房间生成，多楼层+楼梯）+ `changeFloor`（交互式上下楼）+ `measureBuilding`（建筑足印/门定位） |
| **室内移动/交互三函数**（survival.js） | `updateInteriorMode`（每帧：先同步坐标→动作系统→移动→相机→驱动室内战斗）、`doInteriorInteract`（F：优先躲藏幸存者→3×3 箱子）、`updateInteriorPrompt`（算 F 目标画光圈） |
| **室内外统一** | 复用室外 `updateNpc` 分发，canStand 换 `interiorCanStand`、sv.zombies 换室内僵尸 |
| **躲藏幸存者** | 2 层及以上按概率生成友善 NPC，`state:'hide'` 站定不动，交互复用 NPC 菜单 |
| **室内寻路** | `interiorWalkable` / `interiorCanStand` / `getInteriorPathField`（房间 tiles BFS） |
| **交互光圈** | `updateInteriorPrompt` 算 `it.promptTarget`，render 画黄色/金色光圈（与室外一致） |

## 三、关键代码改动

| 位置 | 改动内容 |
|---|---|
| `survival.js:updateInteriorMode` | 先 `sv.px=it.px` 再动作系统（否则抹掉闪现位移）；室内外 NPC 逻辑一致复用 |
| `survival.js:doInteriorInteract` | F 交互：优先躲藏幸存者 → 3×3 箱子 |
| `survival.js:updateInteriorPrompt` | 算 F 目标画光圈（存 `it.promptTarget`） |
| `survival.js:onDeath` | 不再强制 `sv.interior=null`，软核有队友时保留房间，切视角后 `syncControllerInterior` 保持房间 |
| `wnpc.js:switchControl` | 室内切视角先同步坐标（修复 controllerId 位置互换 bug） |
| `windoor.js:spawnInteriorNpcs` | 躲藏幸存者：`INTERIOR_NPC_CHANCE_BASE=0.0015` + 每层 `_PER_FLOOR=0.0003`（wbalance） |
| `windoor.js:enterInterior` / `exitInterior` | 进出：`exitInterior` 室内外 NPC 统一带出（队员移门口外，未招募躲藏者留 it.npcs）；落点只允许真可行走 `isWalk`（不允许 DOOR 防卡建筑轮廓） |
| `windoor.js:interiorWalkable` / `interiorCanStand` / `getInteriorPathField` | 室内寻路（房间 tiles BFS） |
| `windoor.js:updateInterior` | 室内僵尸/战斗循环（复用室外规则，室内 `nz` 简化僵尸） |
| `windoor.js:changeFloor` | 楼梯改**交互式**（站楼梯格旁按 F 触发，不再误走自动换层） |

## 六、历史教训

1. **室内三函数在 survival.js**：`updateInteriorMode`/`doInteriorInteract`/`updateInteriorPrompt` 实现在 survival.js，不在 windoor.js，搜符号时注意（容易找错文件）。
2. **controllerId bug**：室内切视角时 `sv.px=it.px` 用房间记录坐标覆盖玩家位置，若 `it.px` 是旧主控位置会拉回旧位 → 位置跳变。修复：切视角先同步坐标 + onDeath 不强制清 `sv.interior`。
3. **室内外动画同步**：8/9 曾因室内移动块只推 stepT 不推进 `animFrame`/`animMoving` 导致室内走动帧冻结；补上与室外一致的动作系统调用。
4. **楼梯交互式**：改 `changeFloor` 后必须站楼梯格旁按 F 才换层，不再误走自动换层（行为变更）。
5. **落点防卡**：进出室内落点只允许真可行走 `isWalk`，不允许 DOOR，防卡建筑轮廓。
