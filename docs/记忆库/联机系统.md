## 一、领域概述

荒原模组联机基于 **host 权威模型**：host 生成 seed 并做权威模拟，guest 只上报意图 + 画表现。核心红线是**单机/联机零差异**（AGENTS.md §5.1 新功能门槛）——联机除「多玩家共游」外，规则/反馈/数值/特效/音效/UI/掉落/结算/存档必须与单机完全一致。

> 注意：`mpGame.js` 是原版 PvZ 塔防联机（sendSync/sendInput），与荒原 `mpWasteland.js` 是两套独立协议；`net.js` 是两者共用底层（PeerJS 房间层）。

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **host 权威** | host 生成 seed，双端本地确定性生成世界；host 权威处理战斗/掉落/召唤/交易/建造，guest 只上报意图 + 画表现 |
| **消息协议** | 握手 `wstart`（seed/difficulty/character）；`updateGuest` 分流；`wsync`（100ms 快照）、`wevt`（事件）、`wdiff`（双向改地） |
| **34 格空间裁剪** | `serializeMpSnapshot` / `applyMpSnapshot` 只同步玩家视野 34 格内 plants/drops/effects/bullets，视野外无可见差异，走进后 100ms 内出现（P0-3） |
| **战斗同步** | guest 只画特效 + 上报 atk，**guest 禁止本地扣自己 hp**；僵尸带运行时 id（`sv._zIdSeq`）并按 id 合并；掉落 host 生成、guest 拾取上报防重复 |
| **NPC 队伍本地管理** | wsync 不带 npcs 防主控覆盖；guest 操控 NPC 用 `npcctl` 事件，host 让渡该 NPC AI |
| **泰拉瑞亚双档** | 世界档归 host（含双方 wdiff），guest 只落角色档 |
| **断线重连** | guest 重连 → `wrejoin` → host 重发 winit + 立即补 wsync；重连期间 guest 本地世界继续运行 |
| **dev 联机** | 属性类 `devflags` 上报回传（host 权威 → wsync 回传双端共用）；召唤/结算类 `devcmd` host 权威执行 → 双端可见 |

## 六、历史教训（AGENTS.md §6 教训 1-10）

1. 序列化返回结构必须与消费方断言一致（对象 vs `Array.isArray` 不符会静默失效）。
2. host 权威字段，guest 端发起的变更必须上报回传，否则「改了被还原」。
3. 双向全局事件（camp/pause）放 `onWevt` 开头统一处理，直接本地应用不广播防回环。
4. NPC 队伍不随 wsync 同步；guest 操控 NPC 用 `npcctl`，host 让渡该 NPC AI。
5. guest 端禁止直接扣自己 hp，死亡必须同步。
6. 特效/掉落/植物同步做 34 格空间裁剪，视野外无可见差异。
7. 音效必须双端可听：本地播完 outbox `sfx` 通知对端（带 snd 名与参数）。
8. 暂停必须同步（任一端暂停 → 对端同步），防「一端暂停另一端被打」。
9. 僵尸新增必须走 `spawnZombie`（分配 id），禁止手工 push 无 id 对象。
10. 改 wstate.js 后必跑 smoke + full-run；改存档键结构后补双端存档兼容测试。
