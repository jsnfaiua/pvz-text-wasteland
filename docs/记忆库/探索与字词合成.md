## 一、领域概述

「文字侵蚀与具现」核心玩法：**字楔**（wedge: clean / rough / stable 三品级）+ **字源**（glyph 单个汉字）+ **合成配方**（RECIPES）体系，配合搜索系统与像素具象绘制，实现文字到实体的转化。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **字楔/字源/配方体系** | 字楔（品级）+ 字源（汉字）+ 配方（RECIPES）三要素 |
| **纯规则文件** | `wwordcraft-rules.js` **不依赖 DOM/音频/浏览器全局**，供系统与测试共用；`recipeAvailability` 统一判定 |
| **权重概率表（和=1）** | `GLYPH_SOURCE_POOLS` / `ZOMBIE_GLYPH_POOLS` / `GLYPH_COUNT_TABLES` / `WEDGE_SOURCE_TABLES` / `ZOMBIE_POLLUTION_TABLES` 每池权重和=1；`weighted()` 构造器 + `pickWeighted()` 加权抽取 |
| **搜索谜题式揭示** | `openSearch` 物品槽位确定性散落（基于箱子坐标+物品 id 哈希，重开位置不变），逐件按稀有度 `RARITY_TIME` 渐亮揭示 |
| **修复系统** | `repairAvailability` / `repairDuration` + `beginRepair`（残缺字楔修复） |
| **像素具象** | `wpixelmanifest.js PALETTE` + 各物 `pixelsFor` / `drawGlyphs` / `drawObject` / `drawManifestation`：字词合成为像素实体绘制 |

## 六、历史教训

1. **配方必须纯规则化**：合成配方进 `wwordcraft-rules.js`（纯规则文件），禁止依赖 DOM/音频/浏览器全局——这是 smoke-test 能跑、双端能共用的前提（AGENTS.md §13.6）。
2. **概率表权重和必须=1**：所有掉落/字源池权重和=1，smoke-test 有断言，改动必须保持（AGENTS.md §13.6）。
3. **搜索确定性散落**：槽位位置基于坐标+物品 id 哈希，重开位置不变；改动哈希算法会改变搜索体验，需回归。
4. **拿取保留完整对象**：`takeFromSearch` 用 `addItemObj` 保留品级/耐久，禁止用字符串副本丢失对象属性。
