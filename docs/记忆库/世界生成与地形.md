## 一、领域概述

荒原模组采用**无限世界**结构，完全由 seed 确定性生成。本领域负责地形分区、路网/人行道、草地与区块缓存。核心原则：**世界生成与双端必须一致的随机一律走 seed 派生纯函数（`world.js hash2` / `wgrass.js grassNoise`），禁止 `Math.random` 参与世界生成或存档字段**（AGENTS.md §13.2，硬性）。

---

## 二、核心技术

| 技术 | 说明 |
|---|---|
| **seed 确定性生成** | `world.js hash2` 纯函数：同 seed → 同世界，存档只存 seed + 差分（`sv.mods.tiles`），读档按 seed 重建基底再叠加差分 |
| **地形分区** | `wdistrict.js` 圈层模型：core / inner / mid / suburb / wild 五圈层，`districtAt` 查询；城区/郊区/荒野/废墟各有生态与生成规则 |
| **路网生成** | `rawVerticalRoad` / `rawHorizontalRoad` 网格路 + `plannedArterialAt` 主干道折线（axis/line 分离）+ `plannedSidewalkAt` 人行道；走廊跨度 `vCorridorSpan` / `hCorridorSpan` |
| **草地四方连续** | `wgrass.js makeNoiseTile` 无缝噪声瓦片，grassNoise 确定性噪声，草束按占格 bbox 只在草坪生成 |
| **区块缓存** | `chunkOf` 生成 + `purgeChunks` 5s 清理，避免无限世界内存膨胀 |
| **T 表地块** | `wconst.js` TS=36 格宽；`T.FLOOR` 与 `T.SIDEWALK` 同值 `'·'`——诊断/断言必须对象值比较，禁止字面量判等 |

## 三、关键代码改动

| 位置 | 改动内容 |
|---|---|
| `world.js:hash2` | 确定性哈希函数，世界生成/双端同步的随机源（纯函数） |
| `world.js:newSeed` | 生成世界种子（联机 host 生成 seed，双端本地确定性生成） |
| `world.js:chunkOf` / `getTile` / `setTile` | 区块生成与 tile 查询/修改；`setTile` 改动推 `mpOutbox`（联机 wdiff 双向改地） |
| `world.js:purgeChunks` | 区块缓存 5s 清理（P1 性能防线） |
| `world.js:wildSidewalkKept` | 荒野人行道保留判定（修复「荒野人行道缺失与公路断连」） |
| `world.js:plannedArterialAt` | 主干道折线查询；**修复轴/线错配**（arterialInfoAt axis/line 错配曾导致路带断连，8/5 修复） |
| `wdistrict.js:districtAt` / `arterialInfoAt` / `blockAt` | 区域判定 / 主干道信息 / 街区查询 |
| `wgrass.js:makeNoiseTile` | 无缝噪声瓦片；**噪声瓦片 7.111 格周期函数化根治**（8/7 修复「格子状线条」根因） |
| `wgrass.js:grassRenderLayer` | 动态草层，束中心 3×3 占格必须全 GROUND/WEED 才画（草只长草坪，不长人行道/路面） |
| `wconst.js` | TS=36、区块等常量；新增地块类型需四件套（T 表/通行/渲染/序列化，AGENTS.md §13.3） |

## 六、历史教训

1. **确定性是硬约束**：世界生成/存档/联机快照禁止 `Math.random`，必须走 `hash2`/`grassNoise` 纯函数，否则双端不同世界（AGENTS.md §13.2）。
2. **同值地块陷阱**：`T.FLOOR` 与 `T.SIDEWALK` 同值 `'·'`，诊断/断言必须对象值比较，字符串字面量判等会出错（AGENTS.md §4）。
3. **主干道折线 axis/line 错配**：8/5 曾因 axis/line 错配导致路带断连，改路网逻辑前务必核对 `plannedArterialAt` 的数据结构。
4. **噪声周期**：「格子状线条」根因是噪声瓦片周期（7.111 格），8/7 函数化根治——改草地噪声前先确认周期连续性。
5. **半成品地块禁止**：新增地块只画出来不能走属缺陷，必须四件套齐备（AGENTS.md §13.3）。
