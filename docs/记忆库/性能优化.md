## 一、领域概述

本领域是**帧率防线**（AGENTS.md §7 性能红线）。核心铁律：**主循环（RAF）禁止冻结**，任何帧内异常必须被捕获兜底；已落实的性能防线（P0-1 ~ P0-8）**禁止回退**。host 是性能瓶颈端（guest 端 wsync 解析仅 ~0.3ms/拍），优化 host = 优化双端体感。

---

## 二、核心技术（性能防线清单）

| # | 防线 | 技术说明 |
|---|---|---|
| P0-1 | **存档宏任务队列** | `saveNow` 用 `_saveQueued` + setTimeout 0 排队落盘；退出/切后台 `flushSave` 兜底。禁止 RAF 帧内整包 JSON 落盘 |
| P0-2 | **僵尸 A* 流场节流** | 换格触发用 `_pathRebuildCd` 0.35s 冷却复用旧场，仅地形 revision 变化才强制重建。禁止每换格全量重建 |
| P0-3 | **联机快照 34 格空间裁剪** | plants/drops/effects/bullets 只同步视野 34 格内。禁止全量序列化 |
| P0-4 | **驾驶 BFS 分帧** | `chauffeurBfsStep` 按每帧扩展格数跨帧推进（首建 6000 / 重建 3000 格预算，确定性）；乘客落点 null 安全。禁止同步展开 6 万格 / 空 canStand 崩溃 |
| P0-5 | **特效合并键控 Map** | 特效合并用 kind + 12px 桶的 Map，O(1)。禁止线性 find O(n²) |
| P0-8 | **流场 targets 近距化** | 只取尸潮 + 玩家警戒范围（Z_CHASE_RANGE=8 方形）内的僵尸进 targets，`playerAlerted` 门控。禁止全地图僵尸进 targets 周期重建 |
| P1-6 | **NPC 缺字段防御** | `eatFromInv/drinkFromInv/workLog` 缺字段防御。禁止缺字段直接崩溃 |

**实体硬上限（不得绕过）**：特效 ≤50、掉落 ≤150、子弹 ≤80、僵尸场上限 45；NPC 死尸帧边界移除；chunk 缓存 5s 清理。

## 六、历史教训

1. **主循环防崩溃是底线**：任何帧内异常必须被捕获兜底，禁止让游戏卡死白屏（AGENTS.md §7）。
2. **流场是 host 卡顿主因**：8/6 卡顿大排查修复 8 处，流场节流 + 近距化是核心，改流场逻辑会直接回退 host 帧率。
3. **分帧必须确定性**：驾驶 BFS 分帧与 CPU 无关，改它可能破坏「单机/联机一致性」。
4. **上限不得绕过**：特效/掉落/子弹/僵尸场上限是硬防线，绕过会引入帧尖峰。
5. **改性能防线必测**：任何改动都要按 AGENTS.md §9 矩阵跑对应验证，未验证不得提交。
