# 像素具现美术规范

> 状态：v1 可执行规范
>
> 适用范围：文字拼合、物体具现、残缺物、植物生长、玩家/NPC感染、文字僵尸和环境现实失效。

## 一、核心视觉原则

### 1. 健康现实是完整像素画

未感染的人类、幸存者、植物和物体必须是轮廓完整、像素稳定的实体。不能为了强调游戏主题就在健康角色身上添加乱码、扫描线、文字贴图或随机故障。

### 2. 文字是结构，不是装饰

字符必须真正承担物体结构：

- 早期文字是物体的唯一存在形式。
- 生形时像素从汉字笔画边缘生长。
- 半现实阶段，文字笔画与像素结构共同承重。
- 落实后字符缩入内部成为字核，不再覆盖物体表面。
- 感染时反向发生：像素结构失效后，内部文字骨骼暴露。

### 3. 功能部位优先生长

像素不会均匀填满字符。每类物体先形成决定其功能的部位：

- 食物：可食主体。
- 工具：工作端。
- 枪械：枪管、枪膛和机匣。
- 建筑：承重点、边界和门洞。
- 载具：车轮、发动机和底盘。
- 植物：根、茎和攻击/生产器官。
- 人体：健康时整体完整；感染时从受感染部位反向破坏。

## 二、像素规格

### 1. 逻辑像素网格

现有荒原地图单格为36×36画布单位。为保证像素边缘整齐，采用18×18逻辑像素作为单格基础素材，再以2倍整数缩放绘制到36×36。

| 类型 | 逻辑画布 | 游戏显示范围 | 说明 |
| --- | --- | --- | --- |
| 字块/小材料 | 8×8或12×12 | 16×16或24×24 | 背包和地面拾取物 |
| 普通物品 | 16×16 | 32×32 | 食物、工具、字楔 |
| 单格植物 | 18×18 | 36×36 | 可上下溢出2像素增强轮廓 |
| 玩家/NPC | 18×24 | 36×48 | 脚部对齐地图格底边 |
| 普通僵尸 | 18×24 | 36×48 | 与幸存者共用人体比例 |
| 大型僵尸/护甲 | 22×26 | 44×52 | 允许跨格但碰撞仍由逻辑数据决定 |
| 汽车 | 36×18 | 72×36 | 横跨两格 |
| 墙/门/柜 | 18×18 | 36×36 | 可无缝拼接 |

禁止1.5倍、2.5倍等非整数缩放。Canvas绘制必须关闭图像平滑：`imageSmoothingEnabled = false`。

### 2. 像素密度

- 单个物体最多使用5—7种主体颜色，感染字符色另计。
- 轮廓主要为1逻辑像素，重要承重边可用2像素。
- 内部高光面积不超过主体面积的12%。
- 单格物体的零散独立像素不超过8个，避免噪点化。
- 文字到像素的过渡颗粒以2×2小簇为主，不使用均匀粒子雨。

## 三、统一色板

### 世界基础色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深渊黑 | `#0A0C0B` | 背景、最深轮廓 |
| 炭灰 | `#171B19` | 阴影、面板和感染空洞 |
| 骨白 | `#D8D2BD` | 健康字块、纸张和高亮边缘 |
| 脏蓝灰 | `#65727A` | 金属暗面、夜间环境 |
| 枯叶绿 | `#667C45` | 荒原植物基础色 |
| 锈红 | `#A65F3F` | 血肉警告、锈蚀、污染提示 |
| 字楔棕 | `#C0794A` | 粗制字楔和连接点 |
| 警戒琥珀 | `#C7904F` | 具现进行、相容警告 |
| 冷污染青 | `#6B9693` | 轻度文字侵蚀 |
| 深污染红 | `#7E3131` | 重度感染和失名 |

### 用色规则

- 健康实体使用自然材质色，不被统一染成绿色或灰色。
- 文字态统一以骨白为主，但来源域可在阴影中加入轻微色相。
- 字楔是唯一稳定使用琥珀/棕色的连接物。
- 污染色只出现在感染结构，不铺满整个屏幕。
- 不使用高饱和赛博霓虹，不使用彩虹色故障边。

## 四、轮廓、光照与材质

### 1. 轮廓

- 外轮廓使用深渊黑或主体色的最深一级。
- 朝上和朝光面可中断轮廓1—3像素，避免黑色剪纸感。
- 重型物体底部增加一条2像素暗边，表达重量。
- 文字阶段不套物体轮廓；轮廓必须随像素生长逐步出现。

### 2. 光照

- 默认光源来自左上方。
- 每个材质只使用亮面、主体、暗面三个基础明度。
- 具现过程中，字楔提供低强度琥珀光，不形成大面积光晕。
- 落实瞬间通过1帧接触阴影表达重量，不使用白屏闪光。

### 3. 材质语言

- 木材：短直纹、断裂端面和偏暖暗边。
- 金属：冷灰主体、小面积骨白高光、锈红缺口。
- 植物：不规则但成组的叶缘，避免逐像素随机毛刺。
- 食物：轮廓饱满，内部纹理少，确保小尺寸可辨认。
- 人体布料：大色块优先，服装褶皱最多2—3条。
- 感染空洞：使用炭灰纯色，不使用透明棋盘或花哨噪声。

## 五、具现四阶段

### 阶段A：定词（0%—20%）

- 完整名称占据目标物体未来的中心线。
- 字符必须可读，字距稳定。
- 字楔显示在相邻字符连接处，尺寸为3×3或4×4逻辑像素。
- 暂无物体碰撞和接触阴影。
- 字符只允许轻微1像素错位，不能持续快速闪烁。

### 阶段B：生形（20%—55%）

- 从功能部位对应的笔画开始长出2×2像素簇。
- 物体轮廓完成约30%—45%。
- 字符仍保持60%以上可读性。
- 生长遵循结构路径，不以随机噪点填充。
- 每6—8帧新增一批像素，使用阶梯式变化而非平滑缩放。

### 阶段C：赋质（55%—85%）

- 轮廓完成80%以上，材质色和内部暗面出现。
- 字符被物体遮挡，但至少保留一个完整部件或关键偏旁。
- 出现碰撞、重量和低品质功能。
- 允许玩家提前拿取，但成品耐久、效果或安全性降低。
- 字楔逐渐沉入接缝，只剩琥珀色小点。

### 阶段D：落实（85%—100%）

- 字符向物体内部收缩，形成2×2至4×4的字核闪点。
- 最后补齐接触阴影、功能部件和1—2个识别高光。
- 完成帧不闪白，物体向下移动1逻辑像素表达落地。
- 最终外观是完整像素物体，表面不残留大段文字。

## 六、逐帧动画规范

基础具现动画采用12fps视觉帧率，游戏逻辑仍按真实时间推进。

| 物体复杂度 | 关键帧数量 | 循环/停留规则 |
| --- | ---: | --- |
| 食物与材料 | 8帧 | A2帧、B2帧、C3帧、D1帧 |
| 工具与冷兵器 | 12帧 | A2、B4、C4、D2 |
| 枪械与机械 | 16帧 | A3、B5、C6、D2 |
| 建筑部件 | 16帧 | 从承重点向外扩张 |
| 汽车 | 24帧 | 车轮/底盘→发动机→车身→玻璃 |
| 植物生长 | 独立时间轴 | 不套用短时物品动画 |

如果玩家开启“减少闪烁”，所有1帧字符错位改为2帧稳定交替；开启“降低侵蚀强度”后，人体不显示大面积身体缺损，只显示局部字符骨架和色块变化。

## 七、六个母版设计

## 1. 胡萝卜母版

逻辑尺寸：16×16。

- 定词：「胡」「萝」「卜」横向排列，两个字楔连接。
- 生形：从「萝」下部和「卜」竖笔附近长出橙色根部像素。
- 赋质：根部完成，顶部叶片从「胡」上缘形成；文字缩入根部中线。
- 落实：完整胡萝卜，橙色主体3级明度、枯叶绿叶片、左上1像素高光。
- 缺「萝」：主体中段为空洞，上下两部分被细小字符线牵连，不能食用。
- 污染版：根部内部出现深污染红偏旁，食用会增加感染值。

## 2. 手枪母版

逻辑尺寸：16×16，朝右。

- 定词：「手」「枪」排列，字楔位于未来扳机位置。
- 生形：枪管和枪膛先从「枪」右侧笔画形成。
- 赋质：机匣、扳机、握把依次生长；「手」逐渐沉入握把。
- 落实：冷灰金属、深色握把、1像素枪管高光。
- 缺「手」：枪存在但握把无法与角色装备槽连接。
- 缺「枪」：只留下握把和无功能金属轮廓。

## 3. 木墙母版

逻辑尺寸：18×18，可四向无缝拼接。

- 定词：「木」「墙」纵向或横向固定在格子中心。
- 生形：四角承重点和底边最先形成。
- 赋质：木板从两侧向中间填充，字符成为内部梁架。
- 落实：三至四块错缝木板、深色钉点、底部接触阴影。
- 缺「木」：只剩碰撞边界和半透明墙意，耐久持续下降。
- 缺「墙」：木材仍在，但失去阻挡与防线归属。

## 4. 汽车母版

逻辑尺寸：36×18，朝右。

- 定词：「汽」「车」悬在两格中心，字楔位于发动机舱。
- 生形：两个车轮、底盘和发动机先出现。
- 赋质：车身从底盘向上生长，车门、车窗和后备箱形成。
- 落实：锈红或脏蓝灰车身，冷灰玻璃，轮胎与地面接触阴影完成。
- 缺「汽」：车辆可以被推动但不能启动。
- 缺「车」：零件存在却不再被世界识别为载具，碰撞结构散开。
- 残骸：像素车身断裂，字符不是新贴上去，而是从破口内部暴露。

## 5. 豌豆射手母版

逻辑尺寸：18×18；生命类采用生长时间轴。

- 种子修复：先固定「豌豆种子」，形成像素种皮。
- 发芽：根部和茎先出现，健康阶段没有暴露字符。
- 成长：头部、嘴部和叶片逐步形成。
- 成熟：完整像素植物，嘴部轮廓是第一识别点。
- 感染反向：先在嘴部或茎部出现字符缺口，再暴露「射」或「手」的笔画骨架。
- 缺「射」：仍会朝目标转头，但无法生成豌豆弹体。
- 缺「手」：射击方向随机或无法锁定敌人。

## 6. 幸存者母版

逻辑尺寸：18×24，头身比例约1:4，不使用大头Q版。

### 健康形态

- 完整像素身体、清晰服装大色块和稳定轮廓。
- 脸部只使用3—5个像素表达，不追求写实五官。
- 姓名显示在UI或交互提示中，不贴在身体表面。
- 待机动画2—4帧，只表现呼吸和重心变化。

### 感染反向阶段

1. 浮字：受感染部位内部偶发1—2个字符像素，不破坏轮廓。
2. 缺口：局部像素消失，露出对应身体词的笔画。
3. 字骨：文字笔画承担手臂、腿或躯干的一部分结构，动作产生1像素错位。
4. 失名：姓名字符开始缺失，角色轮廓与身份色同时衰退。
5. 文尸：原有人形只剩少量像素残片，主体成为文字感染结构。

健康幸存者和感染幸存者必须一眼可区分，不能让普通服装纹理被误认为感染。

## 八、残缺物与半现实物

### 残缺物

- 缺字位置对应真实像素空洞，不使用问号图标覆盖。
- 剩余结构仍保持原物体方向和比例。
- 空洞边缘显示1像素骨白字符断面。
- 功能缺失通过动画和交互共同表达，例如无光的手电筒、无碰撞的墙。

### 半现实物

- 至少40%仍是可读字符，至少30%已经是像素实体。
- 字符和像素必须在结构上连接，不能上下分层成“字+图片”。
- 没有完整接触阴影，呈现未获得全部重量的状态。
- 被强行拿取时，每移动一步有少量像素落回字符碎片。

## 九、感染表现限制

- 不使用全屏乱码雨。
- 不使用持续色差抖动。
- 不使用随机RGB分离。
- 不使用高频白闪。
- 不用文字覆盖所有角色皮肤。
- 不用大面积血腥掩盖结构设计。
- 不让所有感染物使用同一种破碎模板。

恐怖感来自“熟悉功能正在被语言规则夺走”，而不是来自噪声数量。

文件命名：

```text

<object>-stage-c-frame-01.png
<object>-stage-d.png
<object>-damaged-missing-<glyph>.png
<object>-infected-level-<n>-frame-<nn>.png
```

每张PNG使用透明背景、最近邻缩放和固定逻辑尺寸。图集打包在素材定稿后进行，制作阶段保留独立帧便于修改。

## 十一、首批制作验收标准

六个母版全部满足以下条件后，才能扩展到其余具象物：

- 缩放到游戏尺寸后，1秒内能够认出最终物体。
- 定词阶段的汉字保持可读。
- 生形和赋质阶段能看出像素从笔画结构中生长。
- 落实后没有大段文字残留在表面。
- 健康幸存者完全没有感染字符。
- 胡萝卜、手枪、木墙和汽车的功能部位生长顺序不同。
- 减少闪烁模式下没有高频亮度变化。
- 以100%浏览器缩放和高DPI屏幕检查时没有插值模糊。

## 十二、当前状态

本规范已经确定具现像素风格，但实际六组PNG母版尚未绘制。此前尝试生成视觉样张时，图像生成服务发生网络错误，因此项目中没有加入未经检查的临时图片。下一步应先制作胡萝卜四阶段精灵，以它验证18逻辑像素、2倍缩放和逐帧转换管线，再制作其余五组母版。
