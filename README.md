# 🧟 文字植物大战僵尸 · 荒原模组

浏览器端文字主题 PvZ 游戏 + 无尽荒原生存模组（`mod-wasteland`）。ES Modules，无编译，Node + 静态服务器即可运行。

## 快速启动

| 方式 | 操作 |
|---|---|
| 首选 | 双击 `RUN.bat`（启动 :8000 + 打开游戏） |
| 联机双开 | 双击 `联机对战.bat`（含 PeerServer :9000 + 双独立浏览器实例） |
| 直接启动 | `node server.js`（内置本地 PeerServer） |
| 备用 | `powershell -ExecutionPolicy Bypass -File ps-server.ps1` |

详细启动与联机玩法见 [`docs/启动说明.md`](docs/启动说明.md)。
