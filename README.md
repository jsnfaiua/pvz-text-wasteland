## 维护规范

- 触发词：「知识库」≡「记忆库」（同一套体系）；用户说「更新知识库 / 更新记忆 / 更新知识」时，Agent 自动执行本规范（详见 AGENTS.md §11.11）。
- 新增领域：在 `docs/记忆库/` 建文档 → 在上表追加一行（`#` 连续 + 一句话概述）。
- 追加改动：在对应文档「关键代码改动」追加条目，标注 `文件:函数`、背景/根因/改动。
- 准确性：`文件:函数` 引用必须真实，不确定用模块级描述兜底，禁止虚构。
- 链接校验：改完跑 `node dev-tools/verify-memory-links.mjs`，确认无断链。
- 红线：只新增/维护 `.md`；禁止改游戏源码、既有 docs、`saves/`、`users.json`。
